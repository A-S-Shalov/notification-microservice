# 📬 Notification Microservice (Kafka + Email)

## 📌 Описание

Проект состоит из двух микросервисов:

-   **user-service** --- создаёт и удаляет пользователей, отправляет
    событие в Kafka
-   **notification-service** --- получает событие из Kafka и отправляет
    email пользователю

При: - создании пользователя → отправляется письмо о создании - удалении
пользователя → отправляется письмо об удалении

Также реализовано отдельное REST API для отправки email напрямую (без
Kafka).

------------------------------------------------------------------------

# 🏗 Архитектура

User API → user-service → Kafka → notification-service → Email

# 🚀 Запуск проекта

## 1️⃣ Запуск Kafka

В корне проекта:

docker compose up -d

Проверить контейнер:

docker ps

Kafka должен быть доступен на:

localhost:9092

------------------------------------------------------------------------

## 2️⃣ Запуск сервисов

Запустить по очереди:

-   UserServiceApplication
-   NotificationServiceApplication

------------------------------------------------------------------------

# 📬 Проверка через Postman

## 🔹 Создание пользователя

POST http://localhost:8081/users?email=test@mail.com

В Kafka отправляется:

{ "operation": "CREATE", "email": "test@mail.com" }

Notification-service отправляет email:

Здравствуйте! Ваш аккаунт на сайте ваш сайт был успешно создан.

------------------------------------------------------------------------

## 🔹 Удаление пользователя

DELETE http://localhost:8081/users/test@mail.com

Email:

Здравствуйте! Ваш аккаунт был удалён.

------------------------------------------------------------------------

# 📮 Отдельное API (без Kafka)

POST
http://localhost:8082/api/notifications?email=test@mail.com&operation=CREATE

или

POST
http://localhost:8082/api/notifications?email=test@mail.com&operation=DELETE

# 🧪 Интеграционные тесты

Реализованы интеграционные тесты с использованием:

-   GreenMail (SMTP сервер для тестов)
-   SpringBootTest
-   TestRestTemplate

Проверяется:

-   отправка email через REST API
-   корректность получателя
-   корректность текста письма

Запуск тестов:

mvn test

Тесты проходят успешно (зелёные).
